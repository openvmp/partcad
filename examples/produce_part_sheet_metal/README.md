# //pub/examples/partcad/produce_part_sheet_metal

This example demonstrates a part that is made by bending a flat piece of sheet metal. One drawing holds both halves of that -- the outline the blank is cut to, and the lines it is bent along -- and each half is read out of it by the layers the reference asks for.

## Usage
```shell
pc inspect blank
pc inspect bracket
pc test -f cam-sheet-metal bracket
```

The drawing's bend lines carry their angle, inner radius and direction in
the file's extended data (XDATA), which `pc test` reads off the sketch:

```shell
pc inspect -s 'panel;include=BEND_UP,BEND_DOWN'
```
